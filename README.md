# BasicWebAligner

**BasicWebAligner** is a lightweight web application for pairwise nucleotide sequence alignment.

The application runs entirely in the browser and is hosted using **GitHub Pages**. No installation, backend, or account is required.

## Usage

Open the BasicWebAligner GitHub Pages website in your browser.

Paste two FASTA sequences into the input box:

```fasta
>sequence_1
ACTGACCTGATCGATCGATC

>sequence_2
ACTGACCTGAAAAATCGATCGATC
